# Калькулятор

## Описание

Калькулятор  поддерживает разные типы  данных. Проект состоит из трёх частей: 
* Интерфейс калькулятора (используется фреймворк Qt).
* Калькулятор, реализующий арифметические операции (класс Calculator).
* Контроллер для взаимодействия интерфейса и калькулятора.

## Системные требования

C++17, Qt (Qt Widgets, Qt Creator), STL, qmake.
